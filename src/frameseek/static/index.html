How to Prepare for Real Analysis
  1. Choose NVIDIA/Nebius docs/runtime.example.json or Gemini's docs/runtime.gemini.example.json, prepare local private configuration; placeholder values ​​in the template cannot be run.
  2. The NVIDIA/Nebius route uses a self-hosted media model and the Nebius text service; the Gemini route requires explicit permission to send samples to Google. Credentials are only placed in server environment variables.
  3. The limited amount and number of calls are clarified, the cost and resource cutoff calibration are completed, and then the local operator records the two-level approved budget.
  4. Settings FS_RUNTIME_FILE and FRAMESEEK_MODE=real, check again after restarting the service. The material library will make admission based on the actual number of windows.

Read-only check command:uv run --frozen python -m frameseek.readiness. Budget checks can be appended to existing --owner, this does not approve spending.

This check does not call a model, create a GPU, or approve spending.
