模型角色与版本
如何准备真实分析
  1. 选择 NVIDIA/Nebius 的 docs/runtime.example.json 或 Gemini 的 docs/runtime.gemini.example.json，准备本机私有配置；模板中的占位值不可运行。
  2. NVIDIA/Nebius 路线使用自托管媒体模型和 Nebius 文本服务；Gemini 路线需明确允许将抽样画面发送到 Google。凭据只放服务端环境变量。
  3. 明确有限金额和调用次数，完成费用及资源截止校准，再由本机操作者记录两级批准预算。
  4. 设置 FS_RUNTIME_FILE 和 FRAMESEEK_MODE=real，重启服务后重新检查。素材库会按实际窗口数再做准入。

只读检查命令：uv run --frozen python -m frameseek.readiness。预算检查可附带已存在的 --owner，这不是批准费用。

检查不会调用模型、创建 GPU 或批准费用。
